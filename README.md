
## 🚆 Railway Reservation System

A C++ console-based application that simulates the core features of a railway ticket reservation system. It includes both an **Admin** and **User** interface for managing train details, booking tickets, viewing passenger details, and handling cancellations.

---

### 💻 Features

✅ **Admin Mode**

* Create and maintain the train details database (train number, name, boarding, destination, fares, seat availability, dates)
* Manage user accounts (sign-up, view credentials)
* View passenger reservation records

✅ **User Mode**

* User authentication (sign-up & sign-in)
* Book train tickets
* Cancel booked tickets
* Enquire train details
* Check PNR status

✅ **Reservation Details**

* Class selection (First class / Second class)
* Fare calculations with concessions (military, senior citizens, children below 5)
* Passenger details storage (name, age, travel date, PNR generation)

✅ **Cancellation Handling**

* Cancel reservations
* Refund calculations based on cancellation timing

---

### 🛠️ Technologies Used

* C++ (Console-based)
* File Handling with `.txt` files for persistence
* OOP Concepts (Classes, Objects, Inheritance)
* Standard C++ Libraries

### 📂 How to Run

1. Clone or download this repository.

2. Open any C++ IDE (Turbo C++, Dev C++, Code::Blocks, etc.) or compile via terminal.

3. Compile the main files:

   For example:

   ```
   g++ railway reservation system.cpp -o railway
   ```

   or

   ```
   g++ Railway\ user\ login\ page.cpp -o railway_login
   ```

4. Run the executable:

   ```
   ./railway
   ```

   or

   ```
   ./railway_login
   ```

5. Follow the on-screen menus to explore all system features.
